## GIF for a Modrinth description

Paste this HTML into the description's source editor, without the surrounding code fences. It fills the available description width while keeping the original 16:9 frame.

```html
<img src="https://dcvke.github.io/cinematic-media/banner-hq.gif" alt="Crafting directly in the world with Cinematic Interactions" width="100%">
```

## WebM for a Modrinth description
