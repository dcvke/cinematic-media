# Cinematic Interactions media



Public demonstration media for the Cinematic Interactions Minecraft mod.



The complete 10.8-second crafting demonstration, with its original framing and colors.



**[Watch the preview](https://dcvke.github.io/cinematic-media/)**



| File | Resolution | Frame rate | Size |

| --- | --- | --- | --- |

| [High-quality GIF](https://dcvke.github.io/cinematic-media/banner-hq.gif) | 704 x 396 | 10 fps | 9,837,985 bytes |

| [Full HD WebM](https://dcvke.github.io/cinematic-media/banner-hq.webm) | 1920 x 1080 | 60 fps | 4,832,293 bytes |



Both loop automatically. The WebM has no audio. The GIF uses the full 256-color palette; the WebM retains the source video's BT.709 color metadata. No saturation, brightness, or color grading filters were added.



## GIF for a Modrinth description



Paste this HTML into the description's source editor, without the surrounding code fences. It fills the available description width while keeping the original 16:9 frame.



```html

<img src="https://dcvke.github.io/cinematic-media/banner-hq.gif" alt="Crafting directly in the world with Cinematic Interactions" width="100%">

```



## WebM for a Modrinth description



A WebM is a video, so use a video element instead of Markdown image syntax. The poster also displays while the video loads or if autoplay is unavailable.



```html

<video src="https://dcvke.github.io/cinematic-media/banner-hq.webm" poster="https://dcvke.github.io/cinematic-media/banner-poster.jpg" autoplay loop muted playsinline controls width="1920"></video>

```



The media is hosted on GitHub Pages. The previous `banner.gif` and `banner.webm` files remain available for existing links.



## Three-scene showcase

**[Watch the three-panel banner](https://dcvke.github.io/cinematic-media/showcase-three-scenes.html)**

Hammer strikes on an anvil, an enchanting ritual, and page turning on a lectern play side by side. The montage keeps the original footage colors and uses a short crossfade for the loop. The panel captions use the original Minecraft bitmap font, with crisp pixels and a subtle shadow.
